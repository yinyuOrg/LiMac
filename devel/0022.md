# [0022] 完成提示按操作系统分流：macOS / WSL2 / 原生 Linux，systemd 提示按实际运行状态展示

## 如何验证

1. 语法检查：
   ```bash
   bash -n bin/home-manager-setup
   ```
2. WSL 检测（WSL2 环境应输出 WSL-DETECTED）：
   ```bash
   bash -c 'repo=$(pwd); eval "$(sed "/^main \"\$@\"$/d" bin/home-manager-setup)"; detect_is_wsl && echo WSL-DETECTED; has_systemd && echo SYSTEMD-YES'
   ```
3. 三分支完成提示模拟：
   ```bash
   # WSL2
   bash -c 'repo=$(pwd); eval "$(sed "/^main \"\$@\"$/d" bin/home-manager-setup)"; IS_WSL=true; IS_DARWIN=false; SYSTEM_NAME=x86_64-linux; tmp=$(mktemp -d); HOME=$tmp show_completion; rm -rf $tmp'
   # macOS
   bash -c 'repo=$(pwd); eval "$(sed "/^main \"\$@\"$/d" bin/home-manager-setup)"; IS_WSL=false; IS_DARWIN=true; SYSTEM_NAME=aarch64-darwin; tmp=$(mktemp -d); HOME=$tmp show_completion; rm -rf $tmp'
   # 原生 Linux 且无 systemd
   bash -c 'repo=$(pwd); eval "$(sed "/^main \"\$@\"$/d" bin/home-manager-setup)"; has_systemd() { return 1; }; IS_WSL=false; IS_DARWIN=false; SYSTEM_NAME=x86_64-linux; tmp=$(mktemp -d); HOME=$tmp show_completion; rm -rf $tmp'
   # 分别应出现：chsh + wsl --shutdown / iTerm2 提示 / Konsole + 「未运行 systemd」
   ```
4. 跳过逻辑：
   ```bash
   bash -c 'repo=$(pwd); eval "$(sed "/^main \"\$@\"$/d" bin/home-manager-setup)"; IS_WSL=true; IS_DARWIN=false; configure_konsole; has_systemd() { return 1; }; cleanup_systemd_services'
   # 应分别输出「WSL2 跳过 Konsole 配置」「未检测到运行中的 systemd，跳过服务清理」
   ```

## 2026/08/19 完成提示按操作系统分流

## What

- `bin/home-manager-setup` 新增 `detect_is_wsl()`（检查 `/proc/version` 中 microsoft/wsl 字样）与 `has_systemd()`（检查 `/run/systemd/system`）。
- `main()` 平台检测处新增 `IS_WSL` 标记，平台日志附加 `[WSL2]` 标识。
- `show_completion()` 由 darwin/非 darwin 两分支重构为三分支：
  - macOS：Terminal/iTerm2/VSCode 指向 fish 路径（OPERATIONS §3.2）+「不使用 systemd」；
  - WSL2：直接给出 chsh + `wsl --shutdown` 三行命令（OPERATIONS §3.4）；
  - 原生 Linux：Konsole LiMac profile（OPERATIONS §3.1）。
  - systemd 提示改为按 `has_systemd` 实际判断，无 systemd 的系统不再打印 systemctl 提示。
- `configure_konsole()`：WSL2 直接跳过（info 提示，取代原先「Konsole 未安装」的 warning 噪音）。
- `cleanup_systemd_services()`：darwin 跳过之外新增 `has_systemd` 判断，无 systemd 不再空跑 systemctl。

## Why

- 此脚本此前只区分 darwin/非 darwin：WSL2 用户看到的完成提示是「推荐 Konsole」与 systemd 提示，均与 WSL2 实际环境不符（用户在 WSL2 实测反馈）。
- 无 systemd 的 Linux/WSL2 环境下，systemd 服务提示与 cleanup 步骤属于误导/无效操作。
- 与 [0013] 的说明区分：0013 移除的 `detect_is_wsl` 用于 **profile 预设分支**（被统一自选流程取代）；本次新增的检测仅用于**完成提示与跳过逻辑的展示**，不影响 profile 选择流程。

## 改动说明

| 区域 | 改动 |
|---|---|
| `bin/home-manager-setup` 新增函数 | `detect_is_wsl`、`has_systemd` |
| `bin/home-manager-setup` `main` | 新增 `IS_WSL` 检测；平台日志附加 `[WSL2]` |
| `bin/home-manager-setup` `show_completion` | 三分支平台提示；systemd 提示按实际状态 |
| `bin/home-manager-setup` `configure_konsole` | WSL2 跳过 |
| `bin/home-manager-setup` `cleanup_systemd_services` | 无 systemd 跳过 |

## 验收标准

- `bash -n bin/home-manager-setup` 通过
- WSL2 环境下 `detect_is_wsl` 为真，平台日志带 `[WSL2]`
- 三平台分支提示各自正确；systemd 提示仅在 systemd 运行时出现
- WSL2 下 Konsole 配置与 systemd 清理被正确跳过
- 交互流程（profile 选择、host.nix 生成等）不受影响
