## 2026/08/11 初始化流程改为统一自选 profile，默认全部不启用；每次运行 setup 都提供重选选项

## What

- 移除 `bin/home-manager-setup` 中的 WSL 专属优化提示 (`ask_wsl_optimization`) 与 WSL profiles 模板 (`wsl_profiles_block`)。
- 移除 `detect_is_wsl`：初始化流程不再按是否 WSL 做特殊分支。
- 新增 `select_profiles`：对所有平台统一展示可选 profile 列表，每个 profile 独立 `[y/N]` 询问，**默认全部不启用**。
- 新增 `render_profiles_block`：根据已选列表生成 `host.nix` 中完整的 `profiles = { ... }` 块。
- `generate_host_config` 改为调用 `select_profiles` + `render_profiles_block`，生成显式启用/禁用每个 profile 的 `host.nix`。
- `ensure_wsl_profiles` 重命名为 `ensure_profiles`：当任何平台下的旧 `host.nix` 缺少 `profiles` 块时，统一进入自选流程补齐，不再预设 WSL 优化方案；保留备份与幂等性。
- 新增 `maybe_reselect_profiles()`：当 `~/.config/limac/host.nix` 已存在且包含 `profiles` 块时，每次运行 `bin/home-manager-setup` 都会展示当前已启用的 profile 并询问是否需要重新选择（默认 `N`）。
- 新增 `replace_profiles_block()`：按大括号计数定位并替换现有 `profiles` 块，支持多行和单行格式。
- 新增 `HOST_CONFIG_FRESHLY_WRITTEN` 标记：当 `generate_host_config()` 生成新文件或 `ensure_profiles()` 补齐旧文件时设为 `true`，避免同一轮运行中紧接着又询问重新选择。
- `main()` 中仅当 `HOST_CONFIG_FRESHLY_WRITTEN=false` 时才调用 `maybe_reselect_profiles()`。

## Why

- 原 WSL 优化提示是“默认开启核心 + 语言包，关闭嵌入式/容器”的预设方案；用户希望不论任何场景都由用户自选，避免默认安装不需要的工具。
- 默认全部不启用符合“最小化、显式选择”的原则，用户只安装自己确认需要的 profile。
- 统一所有平台（Linux / macOS / WSL）的交互行为，降低维护复杂度。
- 用户希望每次重新运行 `bin/home-manager-setup` 都能调整 profile 选择，而不是仅在首次初始化或文件缺块时才出现选择界面；默认 `N` 避免误触覆盖。

## 改动说明

| 区域 | 改动 |
|---|---|
| `bin/home-manager-setup` 删除 `detect_is_wsl` | 不再检测 WSL，所有平台统一处理 |
| `bin/home-manager-setup` 删除 `wsl_profiles_block` | 移除 WSL 专属 profiles 模板 |
| `bin/home-manager-setup` 删除 `ask_wsl_optimization` | 移除 WSL 专属优化询问 |
| `bin/home-manager-setup` 新增 `select_profiles` | 统一自选 profile，每个 `[y/N]`，默认 `N` |
| `bin/home-manager-setup` 新增 `render_profiles_block` | 根据已选列表渲染完整 profiles 块 |
| `bin/home-manager-setup` 新增 `replace_profiles_block` | 大括号计数定位并替换现有 profiles 块，支持单行/多行 |
| `bin/home-manager-setup` 新增 `maybe_reselect_profiles` | 已存在 profiles 块时询问是否重选，默认 `N` |
| `bin/home-manager-setup` `generate_host_config` | 改为调用 `select_profiles` + `render_profiles_block` |
| `bin/home-manager-setup` `ensure_wsl_profiles` → `ensure_profiles` | 全平台幂等补齐，逻辑改为自选 |
| `bin/home-manager-setup` `main` | 依次调用 `ensure_profiles`；仅当本轮未写/改过 `host.nix` 时才调用 `maybe_reselect_profiles` |

## 验收标准

- `bash -n bin/home-manager-setup` 通过。
- 默认全部不启用时 `select_profiles` 返回空字符串。
- `render_profiles_block "core java"` 正确输出 core/java 为 true、其余为 false。
- 新生成的 `host.nix` 包含完整 `profiles` 块。
- 旧 `host.nix` 缺少 `profiles` 块时进入自选流程补齐；已有 `profiles` 块时幂等跳过。
- `replace_profiles_block` 能正确替换多行和单行 profiles 块。
- `maybe_reselect_profiles` 默认跳过时不修改文件；选 `y` 后正确更新 profiles 块。
- 首次运行生成 `host.nix` 后，同一轮不再询问“是否需要重新选择 profile？”。
- 旧 `host.nix` 被 `ensure_profiles` 补齐后，同一轮不再询问重新选择。
- 已有 `host.nix` 且本轮未修改时，每次运行都会展示当前 profile 并提供重选入口。
- `nix flake check --no-build` 通过。
