## 如何验证

1. 运行 Nix 检查（pure 模式也可，因为 `home.username` 已有 `mkDefault` 回退）：
   ```bash
   nix flake check --no-build --impure
   ```
2. 确认四个平台输出仍存在：
   ```bash
   nix flake show --impure --all-systems 2>&1 | grep homeConfigurations
   ```
   应看到 `x86_64-linux`、`aarch64-linux`、`x86_64-darwin`、`aarch64-darwin` 四项。

   ```bash
   nix-instantiate --eval --strict -E '
   let flake = builtins.getFlake (toString ./.);

   ' --impure
   ```
   应输出 `[ "ai" "containers" "core" "cpp" "embedded" "java" "python" ]`。
4. 运行格式化：
   ```bash
   nix fmt
   ```

## 2026/07/29 Nix 配置去重

## What

- `home/packages.nix` 中七个重复的 `lib.mkOption { type = bool; default = true; ... }` 块与硬编码的 `imports = [ ./profiles/<name>.nix ... ]` 列表，统一派生自一个 `profileMeta` attrset
- `flakeModules/home-manager.nix` 中硬编码的 `platforms` attrset 改为从 flake-parts 的 `config.systems` 派生，与 `flake.nix` 中声明的 `systems = [ ... ]` 共用同一份列表
- 新增 profile 时只需在 `profileMeta` 添加一项；新增/移除平台时只需改 `flake.nix`

---

## 改动说明

| 区域 | 改动 |
|---|---|
| `home/packages.nix` | 新增 `let profileMeta = { ai = "..."; ... }; profileNames = builtins.attrNames profileMeta;`；`imports` 改为 `map (name: ./profiles/${name}.nix) profileNames`；`options.profiles` 改为 `lib.genAttrs profileNames (name: lib.mkOption { ... description = profileMeta.${name}; })` |
| `flakeModules/home-manager.nix` | 函数参数新增 `config`；删除硬编码的 `platforms = { x86_64-linux = "x86_64-linux"; ... }`；改为 `platforms = lib.genAttrs config.systems (name: name)`；顺手让 `mkHomeConfig` 未使用的 `name` 参数通过 deadnix 检查（重命名为 `_name`） |

## 后续：2026/07/29 修复生成结果未保持 `<name>.enable` 子树结构

### What

- 初次重构 `options.profiles = lib.genAttrs profileNames (name: mkOption {...})` 将每个 profile 直接作为 `mkOption` 的结果，丢失了 `.enable` 子键
- 导致 `config.profiles.python.enable` 等访问路径报错：`expected a set but found a Boolean: true`
- 已改为 `lib.genAttrs profileNames (name: { enable = mkOption {...}; })`

### 改动

| 区域 | 改动 |
|---|---|
| `home/packages.nix` | `options.profiles = lib.genAttrs profileNames (name: { enable = lib.mkOption {...}; });`，确保 `config.profiles.<name>.enable` 仍是合法 bool 选项 |

### 验收

- `nix flake check --no-build --impure` 通过
- `nix run "nixpkgs#home-manager" -- build --flake ".#x86_64-linux" --impure` 能成功构建 `home-manager-generation`
- `~/.config/limac/host.nix` 中 `profiles.embedded.enable = false; profiles.containers.enable = false;` 仍按预期生效
