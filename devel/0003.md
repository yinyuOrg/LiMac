# [0003] 个人 Host 配置外置与多平台支持

## 如何验证

1. 运行初始化脚本，确认本地配置生成到外置目录：
   ```bash
   bin/home-manager-setup
   ```
   检查 `~/.config/limac/host.nix` 是否包含你的用户名和 Git 信息。
2. 确认仓库内不再出现个人配置：
   ```bash
   git status
   ```
   应看不到 `hosts/*.nix` 未跟踪文件。
3. 检查 flake 语法：
   ```bash
   nix flake check --no-build
   ```
4. 按需运行 home-manager 应用：
   ```bash
   # Linux x86_64
   nix run "nixpkgs#home-manager" -- switch --flake .#x86_64-linux --impure

   # macOS Apple Silicon
   nix run "nixpkgs#home-manager" -- switch --flake .#aarch64-darwin --impure
   ```

## 2026/07/25 个人 Host 配置外置与多平台支持

## What

- 将个人配置从 `hosts/<username>.<platform>.nix` 迁移到仓库外的 `~/.config/limac/host.nix`
- 避免用户名、Git 邮箱等个人信息进入 Git 仓库
- 统一使用 `--impure` 让 flake 读取外置本地配置
- `flakeModules/home-manager.nix` 改为固定系统输出，支持四种平台
- 默认模块同时导入 `home/platforms/linux.nix` 与 `home/platforms/darwin.nix` 占位模块（避免在 `imports` 中使用 `pkgs` 导致无限递归）
- `bin/home-manager-setup` 自动识别 `uname -s` / `uname -m` 选择对应输出
- README 新增“已验证平台”说明表

---

## 改动说明

| 区域 | 改动 |
|---|---|
| `.gitignore` | 新增 `hosts/*.nix`，忽略任何仓库内生成的 host 文件 |
| `flakeModules/home-manager.nix` | 移除 `hosts/` 动态扫描；提供 `x86_64-linux` / `aarch64-linux` / `x86_64-darwin` / `aarch64-darwin` 四个固定输出；默认模块无条件导入 `home/platforms/linux.nix` 与 `home/platforms/darwin.nix`；`--impure` 时导入 `~/.config/limac/host.nix` |
| `bin/home-manager-setup` | 生成 `~/.config/limac/host.nix`；移除 `git add` 逻辑；自动识别系统架构；应用命令带 `--impure` |
| `bin/update-flake` | 更新提示命令为新的 home-manager 输出名 |
| `README.md` | 快速开始、日常维护命令改为新方式；新增“已验证平台”小节 |
| `docs/OPERATIONS.md` | 更新项目结构说明、首次设置步骤、日常应用命令、添加新 host 说明、FAQ 11.1 |
| `hosts/yinyu.linux.nix` | 删除，配置已迁移到 `~/.config/limac/host.nix` |

## 验收标准

- 运行 `bin/home-manager-setup` 后，`~/.config/limac/host.nix` 存在且包含正确用户名/Git 信息
- `git status` 中不出现 `hosts/*.nix` 等个人配置文件
- `nix flake check --no-build` 通过
- `x86_64-linux` 与 `aarch64-darwin` 可正常应用配置
- 四个平台输出（`x86_64-linux`、`aarch64-linux`、`x86_64-darwin`、`aarch64-darwin`）均可在 `nix flake show` 中列出
