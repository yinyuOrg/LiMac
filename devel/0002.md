# [0002] Ansible 系统级安装调整

## 如何验证

1. 检查 Ansible playbook 语法：
   ```bash
   ansible-playbook ansible/playbook.yml -i ansible/inventory.ini --syntax-check
   ```
2. 运行系统级安装脚本：
   ```bash
   bin/install-via-ansible
   ```
3. 确认 Docker、Chrome、VSCode、微信按预期安装或保持已安装状态
4. 确认无 `apt_repository`、`ansible_os_family` 等弃用警告

---

## 2026/07/25 Ansible 系统级安装调整

## What

- 仅影响 Ansible 系统级安装相关文件与文档
- 修复 `software-properties-common` 在 Debian 13 不可用的问题
- `apt_repository` 改为 `deb822_repository`，消除弃用警告
- facts 变量改用 `ansible_facts[...]`，消除注入弃用警告
- 清理旧 `.list` 源文件，避免 apt 重复定义
- 将 VSCode 从 Home Manager 迁移到 Ansible 系统级安装
- 移除不再维护的飞书安装及相关文档

---
