## 2026/07/29 清理空模块、fish.nix 残留与 goldfish 替换

## What

- 删除空占位模块 `home/platforms/linux.nix` 与 `home/platforms/darwin.nix`，以及整个 `home/platforms/` 目录
- 删除空目录 `hosts/`（仅含 `.gitkeep`），个人配置已外置到 `~/.config/limac/host.nix`，仓库内不再需要占位目录
- `flakeModules/home-manager.nix` 默认模块移除对该两个空模块的 `imports`
- `home/fish.nix:29` fish 缩写 `cdtmp` 中的 `/tmp/jinser-XXXXXX`（来自其他 dotfiles 残留）改为 `/tmp/limac-XXXXXX`
- `home/fish.nix:15-21` 硬编码的 `/opt/homebrew/opt/llvm@19` 改为 `/opt/homebrew/opt/llvm`（Homebrew 始终为当前 LLVM 版本提供无版本号符号链接），避免升级到 llvm@20 等新版后路径静默失效
- `docs/OPERATIONS.md` 项目结构树同步删除 `platforms/` 与 `hosts/` 节点
- `docs/OPERATIONS.md` 中三处引用外部 `goldfish` flake（`gitee.com/XmacsLabs/goldfish?ref=main`）的连通性测试命令，统一替换为 `nixpkgs#hello`，并去掉 `nix run --refresh` 标志
