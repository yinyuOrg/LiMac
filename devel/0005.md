## 2026/07/29 home-manager-setup 脚本加固

## What

- `bin/home-manager-setup` 安全性与可维护性提升
- `set -e` 升级为 `set -euo pipefail`，捕获未定义变量与管道错误
- 修正常量覆盖：已有 `~/.config/nix/nix.conf` 不再被盲目 `cat >` 清掉，先备份再幂等追加
- `generate_host_config` 中三段几乎相同的 `cat > … << EOF` 块（Darwin / WSL / 默认 Linux）合并为一份模板，仅 WSL 优化块按需插入
- WSL 交互提问抽离为独立函数 `ask_wsl_optimization`，便于复用与测试
- 顶部 `BASH_SOURCE` 处理修复未加引号的展开，并适配 `set -u`

## 改动说明

| 区域 | 改动 |
|---|---|
| `bin/home-manager-setup:4` | `set -e` → `set -euo pipefail` |
| `bin/home-manager-setup:13-18` | `BASH_SOURCE` 改用 `${BASH_SOURCE[0]:-$0}`；所有变量加双引号 |
| `bin/home-manager-setup:56-66` | 新增 `append_nix_conf_line` 幂等追加辅助函数（`grep -qxF` 判存在） |
| `bin/home-manager-setup:68-85` | `enable_experimental_features` 不再覆盖整个 `nix.conf`：先 `cp` 备份为 `nix.conf.bak.<时间戳>`，再追加缺失的 `experimental-features`；移除对 `extra-substituters` / `trusted-public-keys` 的强行写入（保留用户自配） |
| `bin/home-manager-setup:170-184` | `generate_host_config` 内的三段 `cat > host_file << EOF`（Darwin / WSL / 默认 Linux）合并为一份模板，仅按需注入 WSL `profiles` 块 |
| `bin/home-manager-setup:200-227` | 新增 `ask_wsl_optimization` 函数；WSL 交互提问从 `generate_host_config` 中剥离，函数以 `echo` 输出布尔结果 |

## 验收标准

- `bash -n bin/home-manager-setup` 通过
- 三种场景（Darwin / WSL 优化 / 默认 Linux）生成的 `host.nix` 内容与改前完全一致
- 已存在 `~/.config/nix/nix.conf` 时运行脚本：
  - 原文件被备份为 `nix.conf.bak.<时间戳>`
  - 脚本结束后 `nix.conf` 中 `extra-substituters`、`trusted-public-keys` 等用户自定义键值不变
  - 仅当 `experimental-features = nix-command flakes` 缺失时才追加
- 重复运行脚本无副作用（幂等）
- `set -u` 模式下未引入未定义变量引用
